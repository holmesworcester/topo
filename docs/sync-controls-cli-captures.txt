Sync Controls CLI Session Captures
===================================

1. Show default policy (all auto)

    $ topo sync policy show
    {
      "requests": "auto",
      "responses": "auto",
      "forward_on_have": "auto"
    }

2. Set requests to manual

    $ topo sync policy set --requests manual
    {
      "requests": "manual",
      "responses": "auto",
      "forward_on_have": "auto"
    }

3. Set all lanes to disabled

    $ topo sync policy set --requests disabled --responses disabled --forward-on-have disabled
    {
      "requests": "disabled",
      "responses": "disabled",
      "forward_on_have": "disabled"
    }

4. Restore all lanes to auto

    $ topo sync policy set --requests auto --responses auto --forward-on-have auto
    {
      "requests": "auto",
      "responses": "auto",
      "forward_on_have": "auto"
    }

5. Trigger round for specific peer

    $ topo sync round --peer abc123
    peer: abc123deadbeef...
    observed_ids: 3
      aabbccdd...
      11223344...
      55667788...

6. Trigger round for all peers

    $ topo sync round --all
    peer: abc123deadbeef...
    observed_ids: 2
      aabbccdd...
      11223344...

7. Trigger request for specific peer

    $ topo sync request --peer abc123
    peer: abc123deadbeef...
    requested_ids: 1
      aabbccdd...

8. Trigger request for all peers

    $ topo sync request --all
    peer: abc123deadbeef...
    requested_ids: 1
      aabbccdd...

9. Request when disabled returns reason

    $ topo sync policy set --requests disabled
    $ topo sync request --peer abc123
    peer: abc123
    reason: requests lane is disabled by policy
    requested_ids: 0
